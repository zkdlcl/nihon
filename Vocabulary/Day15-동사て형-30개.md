> 💡 **표기 안내**: 한자(よみかた) = 한자 옆에 히라가나 읽는 법 표기!  
> 모든 단어는 **기본형 → て형 → 의미 및 예문** 순서로 정리했어요.

---

## 📌 て형 만드는 규칙 (복습)

| 그룹 | 특징 | 규칙 |
|------|------|------|
| **1그룹** (う동사) | 어미가 う/く/ぐ/す/つ/ぬ/ぶ/む/る | 어미에 따라 **って, んで, いて, いで, して** 로 변환 |
| **2그룹** (る동사) | 어미が 「る」이고 앞이 い/え단 | 「る」를 빼고 + **て** |
| **3그룹** (불규칙) | する, くる 두 개뿐! | **して, きて** 로 변환 |

## 🔵 1그룹 동사 (う동사) - 15개

### 1. 書(か)く ➡️ 書(か)いて
- **읽는 법**: 카쿠 ➡️ 카이테
- **뜻**: 쓰다 ➡️ 쓰고 / 써서
- **예문**: 漢字(かんじ)を書(か)いて覚(おぼ)えます。(칸지오 카이테 오보에마스 / 한자를 쓰고 외웁니다.)

### 2. 飲(の)む ➡️ 飲(の)んで
- **읽는 법**: 노무 ➡️ 논데
- **뜻**: 마시다 ➡️ 마시고 / 마셔서
- **예문**: コーヒーを飲(の)んで話(はな)します。(코-히-오 논데 하나시마스 / 커피를 마시고 이야기합니다.)

### 3. 話(はな)す ➡️ 話(はな)して
- **읽는 법**: 하나스 ➡️ 하나시테
- **뜻**: 말하다 ➡️ 말하고 / 말해서
- **예문**: 日本語(にほんご)で話(はな)してください。(니혼고데 하나시테 쿠다사이 / 일본어로 말해 주세요.)

### 4. 聞(き)く ➡️ 聞(き)いて
- **읽는 법**: 키쿠 ➡️ 키이테
- **뜻**: 듣다/묻다 ➡️ 듣고 / 들어서
- **예문**: 音楽(おんがく)を聞(き)いてリラックスします。(온가쿠오 키이테 리랏쿠스시마스 / 음악을 듣고 휴식합니다.)

### 5. 読(よ)む ➡️ 読(よ)んで
- **읽는 법**: 요무 ➡️ 욘데
- **뜻**: 읽다 ➡️ 읽고 / 읽어서
- **예문**: 本(ほん)を読(よ)んで寝(ね)ます。(혼오 욘데 네마스 / 책을 읽고 잡니다.)

### 6. 行(い)く ➡️ 行(い)って ⚠️ [예외]
- **읽는 법**: 이쿠 ➡️ 잇테
- **뜻**: 가다 ➡️ 가고 / 가서
- **예문**: 銀行(ぎんこう)に行(い)って両替(りょうがえ)します。(긴코-니 잇테 료-가에시마스 / 은행에 가서 환전합니다.)

### 7. 帰(かえ)る ➡️ 帰(かえ)って
- **읽는 법**: 카에루 ➡️ 카에ッ테
- **뜻**: 돌아가다 ➡️ 돌아가고 / 돌아가서
- **예문**: うちに帰(かえ)って休(やす)みます。(우치니 카에ッ테 야스미마스 / 집에 돌아가서 쉽니다.)

### 8. 買(か)う ➡️ 買(か)って
- **읽는 법**: 카우 ➡️ 캇테
- **뜻**: 사다 ➡️ 사고 / 사서
- **예문**: パンを買(か)って食(た)べます。(판오 캇테 타베마스 / 빵을 사고 먹습니다.)

### 9. 待(ま)つ ➡️ 待(ま)って
- **읽는 법**: 마츠 ➡️ 맛테
- **뜻**: 기다리다 ➡️ 기다리고 / 기다려서
- **예문**: ちょっと待(ま)ってください。(춋토 맛테 쿠다사이 / 잠깐 기다려 주세요.)

### 10. 会(あ)う ➡️ 会(あ)って
- **읽는 법**: 아우 ➡️ 앗테
- **뜻**: 만나다 ➡️ 만나고 / 만나서
- **예문**: 友達(ともだ치)に会(あ)って映画(えいが)を見(み)ます。(토모다치니 앗테 에이가오 미마스 / 친구를 만나고 영화를 봅니다.)

### 11. 乗(の)る ➡️ 乗(の)って
- **읽는 법**: 노루 ➡️ 놋테
- **뜻**: 타다 ➡️ 타고 / 타서
- **예문**: バスに乗(の)って行(い)きます。(바스니 놋테 이키마스 / 버스를 타고 갑니다.)

### 12. 作(つく)る ➡️ 作(つく)って
- **읽는 법**: 츠쿠루 ➡️ 츠쿳테
- **뜻**: 만들다 ➡️ 만들고 / 만들어서
- **예문**: ご飯(はん)を作(つく)って食(た)べます。(고한오 츠쿳테 타베마스 / 밥을 만들고 먹습니다.)

### 13. 遊(あそ)ぶ ➡️ 遊(あそ)んで
- **읽는 법**: 아소부 ➡️ 아손데
- **뜻**: 놀다 ➡️ 놀고 / 놀아서
- **예문**: 公園(こうえん)で遊(あそ)んで帰(かえ)ります。(코-엔데 아손데 카에리마스 / 공원에서 놀고 돌아갑니다.)

### 14. 急(いそ)ぐ ➡️ 急(いそ)いで
- **읽는 법**: 이소구 ➡️ 이소이데
- **뜻**: 서두르다 ➡️ 서두르고 / 서둘러서
- **예문**: 急(いそ)いで行(い)きましょう。(이소이데 이키마쇼- / 서둘러 갑시다.)

### 15. 休(やす)む ➡️ 休(やす)んで
- **읽는 법**: 야스무 ➡️ 야슨데
- **뜻**: 쉬다 ➡️ 쉬고 / 쉬어서
- **예문**: ベッドで休(やす)んでください。(벳도데 야슨데 쿠다사이 / 침대에서 쉬어 주세요.)

## 🟢 2그룹 동사 (る동사) - 10개

### 16. 食(た)べる ➡️ 食(た)べて
- **읽는 법**: 타베루 ➡️ 타베테
- **뜻**: 먹다 ➡️ 먹고 / 먹어서
- **예문**: りんごを食(た)べています。(링고오 타베테이마스 / 사과를 먹고 있습니다.)

### 17. 見(み)る ➡️ 見(み)て
- **읽는 법**: 미루 ➡️ 미테
- **뜻**: 보다 ➡️ 보고 / 봐서
- **예문**: テレビを見(み)て笑(わら)います。(테레비오 미테 와라이마스 / 텔레비전을 보고 웃습니다.)

### 18. 起(お)きる ➡️ 起(お)きて
- **읽는 법**: 오키루 ➡️ 오키테
- **뜻**: 일어나다 ➡️ 일어나고 / 일어나서
- **예문**: 朝(あさ)起(お)きて顔(かお)を洗(あら)います。(아사 오키테 카오오 아라이마스 / 아침에 일어나서 세수합니다.)

### 19. 寝(ね)る ➡️ 寝(ね)て
- **읽는 법**: 네루 ➡️ 네테
- **뜻**: 자다 ➡️ 자고 / 자서
- **예문**: 薬(くすり)を飲(の)んで寝(ね)てください。(쿠스리오 논데 네테 쿠다사이 / 약을 먹고 자 주세요.)

### 20. 開(あ)ける ➡️ 開(あ)けて
- **읽는 법**: 아케루 ➡️ 아케테
- **뜻**: 열다 ➡️ 열고 / 열어서
- **예문**: ドアを開(あ)けて入(はい)ります。(도아오 아케테 하이리마스 / 문을 열고 들어갑니다.)

### 21. 閉(し)める ➡️ 閉(し)めて
- **읽는 법**: 시메루 ➡️ 시메테
- **뜻**: 닫다 ➡️ 닫고 / 닫아서
- **예문**: 窓(まど)を閉(し)めて寝(ね)ます。(마도오 시메테 네마스 / 창문을 닫고 잡니다.)

### 22. 教(おし)える ➡️ 教(おし)えて
- **읽는 법**: 오시에루 ➡️ 오시에테
- **뜻**: 가르치다 ➡️ 가르쳐 주고 / 가르쳐 줘서
- **예문**: 日本語(にほんご)を教(おし)えてください。(니혼고오 오시에테 쿠다사이 / 일본어를 가르쳐 주세요.)

### 23. 覚(おぼ)える ➡️ 覚(おぼ)えて
- **읽는 법**: 오보에루 ➡️ 오보에테
- **뜻**: 외우다 ➡️ 외우고 / 외워서
- **예문**: 単語(たんご)を覚(おぼ)えて書(か)きます。(탄고오 오보에테 카키마스 / 단어를 외워서 씁니다.)

### 24. 降(お)りる ➡️ 降(お)りて
- **읽는 법**: 오리루 ➡️ 오리테
- **뜻**: 내리다 ➡️ 내리고 / 내려서
- **예문**: 電車(でんしゃ)を降(お)りて歩(ある)きます。(덴샤오 오리테 아루키마스 / 전철에서 내려서 걷습니다.)

### 25. 忘(わす)れる ➡️ 忘(わす)れて
- **읽는 법**: 와스레루 ➡️ 와스레테
- **뜻**: 잊다 ➡️ 잊고 / 잊어버려서
- **예문**: 傘(かさ)を忘(わす)れて困(こま)りました。(카사오 와스레테 코마리마스타 / 우산을 잊어버려서 곤란했습니다.)

## 🔴 3그룹 동사 (불규칙) - 5개

### 26. する ➡️ して
- **읽는 법**: 스루 ➡️ 시테
- **뜻**: 하다 ➡️ 하고 / 해서
- **예문**: 運動(うんどう)をして汗(あせ)をかきます。(운도-오 시테 아세오 카키마스 / 운동을 하고 땀을 흘립니다.)

### 27. 来(く)る ➡️ 来(き)て ⚠️ [읽기 주의!]
- **읽는 법**: 쿠루 ➡️ 키테
- **뜻**: 오다 ➡️ 오고 / 와서
- **예문**: 早くここに来(き)てください。(하야쿠 코코니 키테 쿠다사이 / 빨리 여기로 와 주세요.)

### 28. 勉強(べんきょう)する ➡️ 勉強(べんきょう)して
- **읽는 법**: 벤쿄-스루 ➡️ 벤쿄-시테
- **뜻**: 공부하다 ➡️ 공부하고 / 공부해서
- **예문**: 日本語(にほんご)を勉強(べんきょう)して日本(にほん)に行(い)きます。(니혼고오 벤쿄-시테 니혼니 이키마스 / 일본어를 공부하고 일본에 갑니다.)

### 29. 料理(りょうり)する ➡️ 料理(りょうり)して
- **읽는 법**: 료-리스루 ➡️ 료-리시테
- **뜻**: 요리하다 ➡️ 요리하고 / 요리해서
- **예문**: 料理(りょうり)して食(た)べます。(료-리시테 타베마스 / 요리해서 먹습니다.)

### 30. 掃除(そうじ)する ➡️ 掃除(そうじ)して
- **읽는 법**: 소-지스루 ➡️ 소-지시테
- **뜻**: 청소하다 ➡️ 청소하고 / 청소해서
- **예문**: 部屋(へや)を掃除(そうじ)してすっきりしました。(헤야오 소-지시테 슷키리시마시타 / 방을 청소해서 개운해졌습니다.)
