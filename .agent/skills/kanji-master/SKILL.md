# 🀄 Kanji Master Skill

이 스킬은 **한자를 구조적으로 파고드는** 몰입형 학습을 위한 스킬입니다.
단순 "뜻 + 읽기" 암기를 넘어, 한자의 **구조(부수/획순/성분)**를 이해하고
**AI 니모닉 스토리**로 장기 기억에 고정합니다.

> ⚠️ **최소 수량 규칙**: 매 세션 **최소 10자** 이상 학습. 부수 분석 + 니모닉 필수 제공.
> ⚡ **한자 난이도 규정 (JPT 400~500점 타겟)**: 
> - N5 수준 기초 한자(車, 食, 飲, 話, 買, 読, 書 등)는 **출제 대상에서 전면 제외**!
> - 사용자는 이미 기본 한자를 알고 있으므로, JPT 400점+ 달성을 위한 **JLPT N4~N3 수준 빈출 한자 및 시각적/의미적 혼동 한자**를 집중 출제합니다.
> - 예: `郵便局` (郵), `準備` (准, 備), `予約` (予, 約), `窓口` (窓), `複雑` (複, 雑), `遠慮` (遠, 慮), `注意` (注, 意), `案内` (案, 内), `練習` (練, 習), `経験` (経, 験), `故障` (故, 障), `約束` (約, 束) 등.

## ⚙️ 실행 순서

### 1단계: 호출 감지 & 한자 특정

사용자가 다음 중 하나로 호출합니다:
- "한자 알려줘 / 가르쳐줘"
- "이 한자가 뭐야: [한자]"
- "부수 설명해줘"
- "[일본어 단어]의 한자 분석해줘"
- "[학습 단어]에 나온 한자 공부"

→ **대상 한자를 최소 10개** 선정하여 집중 분석합니다. (부수 찢기 + 니모닉 필수)

---

### 2단계: 한자 해부 카드 제시

각 한자에 대해 다음 **한자 해부 카드**를 출력합니다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🀄 한자 해부 카드: [한자]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📖 기본 정보
  · 의미(訓):  [한국어 뜻]
  · 음독(音読み / 온요미): [음독]  예: 電(デン)
  · 훈독(訓読み / 훈요미): [훈독]  예: 電 (없는 경우도 있음)
  · JLPT 등급: N[5/4/3/2/1]
  · 획수: [N]획

🧩 부수 (Radical) 분석
  · 부수: [부수 문자] ([부수 이름]) — 의미 힌트: [힌트]
  · 구성 성분: [성분1] + [성분2] + ...
  · 시각화:
    ┌─────────────────────┐
    │  [부수]  +  [나머지] │
    │  = [한자]            │
    └─────────────────────┘

✍️ 획순 (Stroke Order) — 핵심 원칙
  획순 규칙: [위→아래 / 좌→우 / 가로→세로 등]
  [획 번호별 간단 설명 or 주의사항]
  💡 외우기 팁: [이 한자의 획순에서 특히 주의할 점]

🔤 관련 단어 (JPT 빈출 + N5~N3 중요 단어)
  | 단어 | 읽기 | 뜻 | 예문 |
  |------|------|-----|------|
  | [복합어1] | [읽기] | [뜻] | [短い예문] |
  | [복합어2] | [읽기] | [뜻] | [短い예문] |

🧠 AI 니모닉 스토리 (암기 스토리)
  📌 스토리: "[사용자 관심사(애니, 여행, 고양이 등)와 연결된
              부수+성분→의미를 연결하는 짧고 강렬한 이야기]"
  
  💡 기억 포인트: [핵심 연상 키워드]

🔴 혼동 주의 (헷갈리기 쉬운 한자)
  · [비슷한 한자1]: [차이점]
  · [비슷한 한자2]: [차이점]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 3단계: 즉석 퀴즈 (Active Recall)

카드 제시 후 바로 퀴즈 1~2문제:

```
⚡ 즉석 퀴즈!
Q1: 이 한자의 부수는 무엇인가요?
Q2: [관련 복합어]는 어떻게 읽나요?
```

→ 사용자 답변 후 채점 및 피드백

## 📚 한자 사전 참조 기준

이 스킬은 다음 기준으로 사전 데이터를 제공합니다:

### 부수 (Radical) 표준
- **강희자전(康熙字典) 214부수** 체계 사용
- 부수의 **위치별 명칭**: 변(偏/へん), 방(旁/つくり), 관(冠/かんむり), 각(脚/あし), 구(構/かまえ), 요(繞/にょう), 수(垂/たれ)
- 각 부수가 한자에서 **어떤 의미 힌트**를 주는지 항상 설명

### 핵심 부수 목록 (N5-N3 자주 나오는 것)
```
氵(さんずい) — 물 관련
亻(にんべん) — 사람 관련  
木(きへん) — 나무 관련
口(くちへん) — 입/말 관련
言(ごんべん) — 말/언어 관련
金(かねへん) — 금속 관련
日(ひへん) — 태양/날 관련
女(おんなへん) — 여성 관련
手(てへん) — 손/동작 관련
心(こころ) — 마음 관련
```

## 💡 AI 니모닉 생성 가이드

### 사용자 맞춤 연상 소재 (User-Brain-Profile 기반)
- **하루카 시나리오**: 카페/편의점/여행 일상 장면에서 한자가 등장하는 스토리
- **유키 선생님 해설**: 시험에 나오는 포인트를 학원 강사 톤으로 설명
- **고양이(猫)**: 고양이 관련 상황으로 스토리 구성
- **여행**: 일본 여행 상황에서 한자 등장
- **한국어 한자**: 한국어 한자음과 연결 (동일한 한자 문화권 활용)

### 니모닉 작성 원칙
1. **부수 → 의미 사슬**: 부수가 뜻하는 것 + 나머지 성분 = 전체 의미
2. **짧고 강렬하게**: 1~2문장으로 압축
3. **감정적 연결**: 재미있거나 기억에 남는 이미지 사용
4. **한국어 한자음 활용**: 이미 아는 한자음으로 브리징

### 예시 템플릿
```
[한자] = [부수(뜻)] + [성분(뜻)]
스토리: "[부수 이미지]가 [성분 이미지]를 만나 [전체 의미] 상황이 된다"
```
