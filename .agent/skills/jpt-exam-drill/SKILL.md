# JPT Exam Drill Skill

이 스킬은 **JPT 시험 1개월 전** 집중 훈련을 위한 실전 문제 생성 및 채점 스킬입니다.
사용자가 "JPT 문제 풀자", "오늘 Part 5 연습", "오문정정 해줘" 등으로 호출합니다.

---

## 🎯 JPT 시험 구성 (참조용)

| 파트 | 영역 | 내용 | 문항 수 |
|------|------|------|---------|
| Part 1~4 | 청해 | 사진묘사/질의응답/회화문/설명문 | 100문제 |
| Part 5 | 독해 | 정답 찾기 (어휘/문법 4지선다) | 30문제 |
| Part 6 | 독해 | 오문정정 (밑줄 4개 중 틀린 것 찾기) | 20문제 |
| Part 7 | 독해 | 공란 메우기 (문장/어휘 선택) | 20문제 |
| Part 8 | 독해 | 장문 독해 | 30문제 |

## ⚙️ 실행 순서

### 1단계: 컨텍스트 로딩
다음 파일을 참조하여 사용자의 현재 상태를 파악합니다:
- `Resources/User-Brain-Profile.md` → 취약점, JPT 파트별 약점 확인
- 최근 `Daily-Logs/` 파일 → 최근 오답 패턴 확인

### 2단계: 파트 결정
- 사용자가 파트를 지정하면 해당 파트 문제 생성
- 지정하지 않으면 `User-Brain-Profile.md`의 **JPT 취약 파트** 기준으로 자동 선택
- 기본 세트: **Part 5 × 3문제 + Part 6 × 2문제** (혼합 5문항)

### 3단계: 문제 생성 규칙

#### Part 5 - 정답 찾기 (어휘/문법)
```
형식: 빈칸에 들어갈 가장 알맞은 것을 고르세요.
彼女は毎日図書館___勉強します。
① を  ② で  ③ に  ④ が
```
- 조사 혼동 (に vs で vs を), 어휘 선택, 문법 패턴 위주
- 반드시 4지선다 형식

#### Part 6 - 오문정정
```
형식: 밑줄 친 부분 중 어색한 것을 고르세요.
①彼は ②昨日 ③学校に ④行きしました。
```
- 사용자의 기존 오답 패턴(い형용사+でした, じゃないでした 등)을 의도적으로 함정에 넣기
- 반드시 밑줄 4개 중 1개가 오답인 형식

#### Part 7 - 공란 메우기
```
형식: （　）에 들어갈 가장 알맞은 것을 고르세요.
明日、友達（　）映画を見に行くつもりです。
① と  ② を  ③ が  ④ で
```

### 4단계: 채점 및 피드백
- 사용자 답안 제출 후 문제별 ⭕/❌/△ 채점
- 오답은 **왜 틀렸는지** 규칙 기반 해설 제공
- 반복 오답 패턴 발견 시 → `User-Brain-Profile.md`의 `JPT 파트별 약점` 섹션 업데이트 제안

### 5단계: 세션 종료 기록
세션 종료 시 오늘의 성과를 Daily Log에 기록할 수 있도록 요약 제공:
```
오늘 JPT 드릴 결과: Part5 3/3 ⭕ | Part6 1/2 ❌ (오문정정 약점 확인)
```

## 💡 응답 가이드
- 문제를 낼 때는 실제 시험지처럼 **번호 매기기, 밑줄 표시, 4지선다** 형식을 철저히 준수
- 채점 피드백은 냉정하지만 격려하는 톤 유지 (⭕❌ 이모지 활용)
- 한 세션에 최대 5문항만 출제하여 집중도 유지
- 해설 시 반드시 **규칙 이름**(예: "1그룹 동사 て형 규칙")을 명시
