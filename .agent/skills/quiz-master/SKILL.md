# 🎯 Quiz Master Skill (v2.0 — FSRS 기반 강화)

이 스킬은 사용자가 "오늘 복습 퀴즈 내줘", "테스트 시작", "SRS 복습" 등으로 호출합니다.

---

## 🎯 목표

**FSRS (Free Spaced Repetition Scheduler) 원칙** 기반으로,
`User-Brain-Profile.md`의 취약점 데이터와 최근 `Daily-Logs`를 분석하여
**"지금 이 순간 가장 복습이 필요한 내용"**을 우선 출제합니다.

---

## ⚙️ 실행 순서

### 1단계: RAG 데이터 수집 (Smart Retrieval)

다음 파일들을 확인합니다:
- `Resources/User-Brain-Profile.md` — 취약점, 관심사, JPT 파트별 약점
- 최근 2~3개 `Daily-Logs/` — `difficulties` 배열과 오답 패턴 확인
- `Vocabulary/한자-마스터-노트.md` — 최근 학습한 한자 확인 (파일 있는 경우)

### 2단계: SRS 우선순위 결정

FSRS 원칙에 따라 출제 우선순위 결정:
```
🔴 최우선: 최근 Daily-Log에서 difficulties에 기록된 항목
🟡 우선: User-Brain-Profile 아킬레스건 (반복 취약점)
🟢 보통: 최근 3~5일 내 새로 배운 내용
🔵 선택: 장기 미복습 (2주 이상) 항목
```

### 3단계: 퀴즈 세트 생성 (5문제 고정)

아래 5가지 유형으로 구성합니다 (순서는 취약점에 따라 조정):

#### 문제 유형

**1️⃣ [조사 퀴즈]** — は/が, に/で 등 헷갈리는 조사
```
빈칸에 알맞은 조사를 넣으세요:
図書館___本を借ります。
```

**2️⃣ [시제/활용 변환]** — い형/な형/동사 활용
```
아래 형용사/동사를 지정된 형태로 변환하세요:
忙しい → 과거형:  / 과거부정: 
```

**3️⃣ [한자 읽기 퀴즈]** ⭐ 신규 추가
```
아래 한자의 읽기를 히라가나로 적으세요:
電気 ( ? ) / 郵便局 ( ? ) / 天気 ( ? )
```

**4️⃣ [작문]** — 취약 문법 + 최근 어휘 조합 한→일 작문
```
아래 한국어를 일본어로 작문하세요:
"[사용자 관심사 기반 상황 문장]"
```

**5️⃣ [함정 찾기 / 오답 패턴 복습]**
- 사용자 오답 패턴(い형용사+でした, じゃないでした 등)을 문장에 의도적으로 넣기
```
아래 문장에서 틀린 부분을 찾아 교정하세요:
「昨日はとても忙しかったでした。」
```

---

### 4단계: 피드백 및 채점

사용자 답안 제출 후:
- 문제별 ⭕/❌/△ 채점
- 오답: "왜 틀렸는지" 규칙 기반 + 취약점 연결 설명
- 정답: "완벽해요!" + 심화 팁 1줄 추가

```
채점 결과: [N]/5 ✅

[1] ⭕ 완벽합니다!
[2] ❌ [오류 설명]
    규칙: [규칙명] — [설명]
    취약점 연결: User-Brain-Profile의 "[약점명]" 항목과 동일한 패턴입니다.
[3] △ 아쉽습니다 — 거의 맞았는데...
```

### 5단계: SRS 피드백 & 다음 복습 예고

```
📊 오늘의 SRS 결과
⭕ 잘 된 부분 → 다음 복습: [3~5일 후]
❌ 취약 부분 → 내일 다시 출제 예정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💡 오늘 발견한 새로운 취약점: [있으면 명시]
→ User-Brain-Profile 업데이트 제안: Y/N?
```

## 🆕 한자 퀴즈 추가 가이드 (2026 업그레이드)

이전까지 없었던 **한자 읽기 퀴즈**를 매 세션에 1~2문제 포함합니다.

### 출제 기준
1. `Vocabulary/한자-마스터-노트.md`에 기록된 최근 학습 한자 우선
2. User-Brain-Profile 취약점 #4 (한자 혼동 목록) 우선
3. 오늘 학습한 단어의 한자

### 한자 퀴즈 형식
```
🀄 한자 퀴즈
다음 한자의 올바른 읽기는?
(A) 郵便局 (B) 電気 (C) 天気 (D) 図書館
→ 히라가나로 읽기를 적어주세요
```
