## ⚡ 모드 선택 (자동 판단)

사용자의 요청에 따라 **3가지 모드** 중 자동 선택합니다.

### 📚 [학습 모드] — 새 문법/어휘/한자 학습
- 호출: "일본어 공부 시작", "Day N 시작", "오늘 문법 배우자", "오늘 한자 공부하자"
- 실행: 계획 확인 → Daily Log 생성 → 문법·한자 설명 → 예문 → 퀴즈

### 🎯 [시험 모드] — JPT 1개월 스프린트 (2026-07-08 ~ 2026-08-08)
- 호출: "시험 준비", "오늘 시험 공부", "JPT 대비"
- **즉시 `jpt-exam-drill` 스킬 연계 실행**
- 실행: 취약점 확인 → 오답 복습 → JPT 문제 5문항 → 빈출 어휘 10개

> ⚠️ **2026-08-08 시험 당일까지**: 새 문법보다 JPT 문제 반복 우선!

### 🔄 [복습 모드] — 기존 학습 내용 복습 + SRS 강화
- 호출: "복습하자", "오늘 복습", "어제 배운 거 다시"
- **즉시 `quiz-master` 스킬 연계 실행**

## ⚙️ 실행 순서 (학습 모드 기본)

### 1단계: 컨텍스트 로딩 (RAG)

세션 시작 시 반드시 다음 파일을 참조합니다:
- `Resources/User-Brain-Profile.md` → 현재 수준, 취약점, 관심사 파악
- 최근 `Daily-Logs/` 파일 (최신 1~2개) → 최근 오답/학습 내용 확인
- `Week1-2-계획.md` → 오늘 학습해야 할 항목 확인

### 2단계: 세션 브리핑 출력

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📅 [날짜] — Day [N] 학습 세션 시작!
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⏳ 시험까지: D-[N]일 남음
🔴 오늘 집중 타겟 (취약점): [User-Brain-Profile 기반]
📋 오늘의 목표:
  1. [학습 항목 1]
  2. [학습 항목 2]
  3. 한자 학습: [오늘의 한자 1~2자]
예상 소요 시간: [N]분
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 3단계: Daily Log 생성

`Daily-Logs/YYYY-MM-DD-DayN.md` 파일 생성 (YAML Frontmatter 포함):
```yaml
---
date: YYYY-MM-DD
day_number: N
tags: [Week?, 학습주제, JPT스프린트]
mastery_score: 
difficulties: []
kanji_studied: []
status: in_progress
---
```

### 4단계: 학습 진행 (모듈 방식)

아래 모듈 중 오늘의 계획에 맞게 선택·조합합니다:

#### 📝 문법 모듈
→ `grammar-tutor` 스킬의 [문법 설명 모드] 연계
- 핵심 규칙 → 예문 3개 → 연습 문제 1~2개

#### 🀄 한자 모듈 (⚠️ 매 세션 **최소 10자** 필수! JPT 400+ 난이도 기준)
→ `kanji-master` 스킬 연계
- N5 기초 한자는 제쳐두고, JPT 400점 이상 달성을 위한 **JLPT N4~N3 수준 실전 빈출 한자 최소 10자** 해부
- 부수 찢기 + 성분 분석 + AI 니모닉 스토리 제공
- 즉석 퀴즈 → SRS 카드 제안

#### 📖 어휘 모듈
- 오늘의 新단어 5~10개 (JPT 빈출 어휘 우선)
- 예문과 함께 제시
- Anki CSV 포맷 제안

#### 🎯 JPT 드릴 모듈
→ `jpt-exam-drill` 스킬 연계 (시험 스프린트 기간)
- Part 5/6/7 중 오늘의 취약 파트 집중

### 5단계: 학습 완료 후 기록

- 오늘 배운 내용 요약
- Daily Log 업데이트 (mastery_score, difficulties, kanji_studied 기입)
- User-Brain-Profile 업데이트 제안 (새로운 취약점 발견 시)
- Git commit 제안:
  ```powershell
  git add .; git commit -m "Day [N]: [오늘 학습 주제] 완료"; git push origin main
  ```

## 🆕 2026 AI-Native 업그레이드 포인트

### SRS (간격 반복 학습) 원칙 적용
- **FSRS 개념**: 최근에 틀린 것을 더 자주 → 잘 아는 것은 간격을 늘림
- 매 세션 시작 시 이전 오답을 **먼저 복습**하고 새 내용 진행
- `difficulties` 배열에 기록된 항목이 있으면 → 반드시 드릴 후 새 학습

### 컨텍스트 기반 학습 (Contextual Learning)
- 단어/문법을 **독립적으로** 가르치지 않고 항상 **실제 예문 속에서** 제시
- AI 튜터 캐릭터(하루카/유키 선생님, 여행, 고양이) 소재를 예문에 활용
- 롤플레잉 시 grammar-tutor의 **캐릭터 듀오 시스템** 활용 (일상 → 하루카, 교정 → 유키 선생님)

### Active Recall 강제
- 예문을 보여주고 번역만 시키는 것이 아니라
- **"아래 상황에서 일본어로 말해보세요"** 방식으로 능동적 산출 유도
