# Japanese Study Session Skill

이 스킬은 매일 일본어 학습 세션을 시작할 때 사용합니다.

## 실행 순서

### 1. 현재 진도 확인
- `Week1-2-계획.md` 파일을 열어 오늘이 몇 일차인지 확인
- 오늘의 학습 목표 체크리스트 확인

### 2. Daily Log 생성
- `Daily-Logs/` 폴더에 오늘 날짜로 새 파일 생성
- 형식: `YYYY-MM-DD-Day{N}.md`
- 템플릿 적용

### 3. 학습 시작 안내
사용자에게 다음 정보 제공:
- 오늘의 학습 목표 (문법/어휘/연습)
- 예상 소요 시간
- 학습 순서 제안

### 4. 대화형 학습 진행
- 문법 설명 및 예문 제공
- 어휘 학습 및 암기 팁
- 연습 문제 출제
- 실시간 피드백

### 5. 학습 완료 후
- 오늘 배운 내용 요약
- Daily Log에 기록
- 체크리스트 업데이트 안내
- Git commit 제안

## ⚡ 모드 선택 (중요!)

이 스킬은 **두 가지 모드**로 동작합니다. 사용자의 요청에 따라 자동 판단합니다.

### 📚 [학습 모드] - 기본 (새로운 문법/어휘 학습)
- 호출: "일본어 공부 시작", "Day N 시작", "오늘 문법 배우자"
- 실행 순서: 오늘 계획 확인 → Daily Log 생성 → 문법 설명 → 예문 → 퀴즈

### 🎯 [시험 모드] - JPT 1개월 스프린트 (2026-07-08 ~ 2026-08-08)
- 호출: "시험 준비", "오늘 시험 공부", "JPT 대비"
- **시험 모드에서는 `jpt-exam-drill` 스킬을 즉시 연계 실행합니다.**
- 실행 순서:
  1. `Resources/User-Brain-Profile.md` 취약점 확인
  2. 어제 오답 복습 (최근 Daily Log 참조)
  3. JPT 실전 문제 5문항 출제 (`jpt-exam-drill` 형식 적용)
  4. 채점 + 해설
  5. 오늘의 빈출 어휘 10개 제시 (`Vocabulary/JPT-빈출-어휘-100개.md` 참조)
  6. Daily Log 및 User-Brain-Profile 업데이트

> ⚠️ **2026-08-08 시험 당일까지**: 새로운 문법 학습보다 JPT 문제 풀이 반복 우선!

## 사용 예시

사용자가 "일본어 공부 시작" 또는 "Day N 시작" 등으로 호출하면:

1. 오늘의 학습 계획 표시
2. Daily Log 자동 생성
3. 첫 번째 학습 항목부터 시작
4. 대화형으로 진행

사용자가 "시험 준비" 또는 "JPT 대비"로 호출하면:

1. User-Brain-Profile 취약점 로드
2. 전날 오답 복습
3. 실전 문제 5문항 → 채점 → 빈출 어휘 제시
