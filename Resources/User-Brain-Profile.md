- **수단 조사**: `で` (車で行きます) 자연스럽게 사용
- **호불호/소망**: `~が好き/嫌い/欲しい` 앞의 `が` 사용 완벽
- **명사 수식**: な형용사 + な + 명사 (`静かな町`) 정확
- **구어체 부정**: `〜じゃないです` 자연스러운 활용
- **て형 기본 변환**: 2그룹/3그룹 변환 안정적, 1그룹 규칙(って/んで/いて/いで/して) 이해

## 🔴 아킬레스건 / 반복 취약점 (Weaknesses)
*AI 노트: 다음 세션과 JPT 문제에서 집중 타격(Drill) 하세요.*

### 1. い형용사 과거형 — 이중 시제 환각
- **증상**: `かった` 뒤에 자꾸 `でした`를 붙임
- **❌ 오답 패턴**: `忙しいでした`, `忙しかったでした`
- **✅ 정답**: `忙しかったです`
- **JPT 연계**: Part 6 오문정정에서 함정으로 자주 등장

### 2. な형용사 과거 부정형 혼동
- **증상**: 과거 부정형에서 `じゃないでした` 사용
- **❌ 오답 패턴**: `親切じゃないでした`
- **✅ 정답**: `親切じゃありませんでした` 또는 `親切じゃなかったです`
- **JPT 연계**: Part 5/6에서 빈번 출제

### 3. 예외 동사 `行く`의 て형
- **증상**: `行く` → `して` (する의 て형으로 혼동)
- **❌ 오답**: `行いて`, `して`
- **✅ 정답**: `行って` (잇테) — 유일한 く동사 예외
- **처방**: 볼 때마다 "行く는 例外!" 암기 강조

### 4. 한자/어휘 시각적 구조 파악: 
  - `郵便局`(郵) vs `湯`(湯) 퀴즈 마스터 돌파!
  - `暖`(日해:따뜻하다) vs `難`(隹새:어렵다) 시각적 부수 구분 완벽!
  - `困`(木:곤란하다) vs `因`(大:원인) vs `囲`(井:둘러싸다) 囗(울타리) 3형제 마스터!
  - 감정 3선 `怒(おこる)`, `笑(わらう)`, `泣(なく)` 완벽 습득!

### 5. 〜たい/たくない 접속 오류 ⭐ (2026-07-23 타파 완료! ✅)
- **증상**: `たい/たくない`를 て형에 붙이던 습관 → **`ます`형 어간** 접속 확립!
- **✅ 정답**: `飲(の)みたくない` (ます형 어간 + たくない)
